# Audio Deepfake Detection

This module detects deepfake audio using MFCC features and a machine learning model.

## How to Train
python ml_scripts/train_model.py

## How to Predict
python predict.py sample.wav

## Dataset
Dataset is not uploaded due to GitHub best practices.

## Model File
The trained audio deepfake detection model is not uploaded to GitHub
due to GitHub file size limitations. The training script can be used
to regenerate the model.
